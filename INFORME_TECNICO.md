# Informe técnico de trabajo

La base recibida incluía un informe que describía comportamiento distinto al código actual. Para evitar afirmaciones desactualizadas, el contenido vigente está en:

- `CAMBIOS_Y_DEFENSA.md`: arquitectura, decisiones y comparación con la base.
- `GUIA_SUPABASE.md`: configuración reproducible.
- `VALIDACION.md`: evidencia y pendientes.

El informe académico final de 4–8 páginas se debe completar con capturas del flujo real una vez configurado Supabase. La vista previa de solo lectura no es evidencia de Auth, Kafka, RLS o Realtime. Se conserva la licencia del proyecto de partida.
