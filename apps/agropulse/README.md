# App AgroPulse

Ver el README de la raíz (`../../README.md`) y la guía de Supabase (`../../GUIA_SUPABASE.md`).

Vista previa: configurar `EXPO_PUBLIC_VISUAL_PREVIEW=true` en `.env` y ejecutar `npm run web`.
Backend real: desactivar esa variable, configurar URL/clave pública y seguir la guía.

Pruebas: `npm test`, `npx tsc --noEmit`, `npm run lint`.
